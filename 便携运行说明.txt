家电技术创新关键词发散工具 - 便携版

运行要求
1. 目标电脑需要安装 Node.js 18 或更高版本：https://nodejs.org/
2. 压缩包已经包含运行依赖，不需要执行 npm install。

macOS 启动方法
1. 解压 ZIP。
2. 双击 start-mac.command。
3. 浏览器访问 http://localhost:3000/
4. 如果系统阻止启动，请右键 start-mac.command，选择“打开”。

Windows 启动方法
1. 解压 ZIP。
2. 双击 start-windows.bat。
3. 浏览器访问 http://localhost:3000/

AI 与 Mock 模式
1. 压缩包不包含任何 API Key，默认可以使用 Mock 数据演示。
2. 如需 AI 功能，将 .env.example 复制为 .env，并在 AI_API_KEY= 后填写自己的 Key。
3. API Key 只能保存在本机 .env 中，不要放入前端或公开分享。

停止服务
关闭启动脚本的终端窗口，或在终端中按 Ctrl+C。

常见问题
1. 如果 3000 端口被占用，可在 .env 中设置 PORT=其他端口。
2. 不要直接双击 index.html，完整功能需要通过 Node.js 后端运行。
